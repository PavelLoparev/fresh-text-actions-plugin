# fresh-text-actions-plugin

Adds encode, decode and text transform actions for developers

## Installation

Install via Fresh's package manager:
```
:pkg install fresh-text-actions-plugin
```

Or install from this repository:
```
:pkg install https://github.com/PavelLoparev/fresh-text-actions-plugin
```

## Usage

Plugin adds the following encode/decode commands:
- `string_to_base64`
- `base64_to_string`
- `json_byte_array_to_hex_string`
- `hex_string_to_json_byte_array`
- `string_to_json_string`
- `json_string_to_string`
- `string_to_uri_encoded`
- `uri_encoded_to_string`
- `string_to_uri_component_encoded`
- `uri_component_encoded_to_string`

Plugin adds the following text transform commands:
- `string_to_kebab_case`
- `string_to_title_case`
- `string_to_snake_case`
- `string_to_camel_case`
- `string_to_pascal_case`
